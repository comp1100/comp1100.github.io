# COMP1100/COMP7110

These are the markdown source for the notes of the course COMP1100/COMP7110 at The University of Queensland.

The student-facing site contains the course overview, studio worksheets, and one-on-one meeting guides. Innovation readings are maintained separately in the [Introduction to Software Innovation](https://uq.pressbooks.pub/introduction-software-innovation/) ebook; they are not authored in this repository.

To build the notes, you will need to install [Jupyter Book](https://jupyterbook.org/).

Run `build.bash` to generate the site in `_build/html`. The `publish.bash` script mirrors that generated output into the adjacent `comp1100.github.io` repository, then commits and pushes the publication repository. Files under `blackboard/` and `private/` are excluded from the generated site.

These notes are maintained by [Eban Escott](mailto:e.escott@uq.edu.au) for COMP1100 and [Hajar Abedi](mailto:h.abedi@uq.edu.au) for COMP7110.
